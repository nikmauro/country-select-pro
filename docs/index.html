CountrySelect Pro

Lightweight, zero-dependency vanilla JavaScript country selector

Flags · phone codes · search · custom lists · accessible · Bootstrap 5 or plain CSS · htmx ready

⭐ GitHub npm 📦 jsDelivr

Version 6.2.0 · MIT

Installation

Add the script, then the class country-select to any input or select.

<script src="https://cdn.jsdelivr.net/npm/country-select-pro@6.2.0/dist/country-select.min.js" defer></script>

<input type="text" class="country-select" name="country" value="GR">
npm install country-select-pro

import CountrySelect from 'country-select-pro'; // ES module + TypeScript types
import 'country-select-pro/css';                 // optional: CSS file (strict CSP)

new CountrySelect('#country', { preferredCountries: ['GR', 'CY'] });

Examples

Every demo below is live; the code under it is exactly the HTML that runs. More standalone pages in docs/examples.

Country (ISO code)

The input value is the ISO code (GR). Search ignores accents: try cote or curacao.

Phone code + Bootstrap input group

data-value-type="phone" stores +30. Search by number: type 357.

Preferred countries

Shown first, with a divider. A shared phone code (+1) resolves to the main country.

<select> – progressive enhancement

Your own list in the HTML: works without JavaScript and is crawlable. Option texts are kept.

Custom list – inline JSON

Codes only, or your own names / values. "flag": false for non-country items, data-sort="false" keeps your order.

Custom list – URL / ajax

Any JSON: [...], {countries: [...]}, {"GR": "Greece"}. Missing names / phone codes come from the built-in list.

Localized names

data-lang translates country names with Intl.DisplayNames (any language). Search accepts both: ελλαδα or greece.

Validation

required works with native validation, Bootstrap's .was-validated and .is-invalid.

Events & API

country-change (plus change / input) and methods on the instance.

Plain CSS theme (no framework)

Set --cs-* variables on any parent. Without Bootstrap the defaults are used.

Disabled · readonly · no search · no flags

States follow the input; data-country-search="false", data-flags="false".

Bootstrap dark mode

Inside data-bs-theme="dark" colors follow Bootstrap automatically – no extra CSS.

Not clipped – modals, offcanvas, overflow

The list opens in the browser's top layer (Popover API): this box has overflow: hidden, yet the list is fully visible. The same in Bootstrap modals / offcanvas and <dialog>.

More: htmx (swap, morph, history) · without any framework · JavaScript API · all examples

Events & API

Elements with the class country-select are initialized automatically (also after htmx swaps); new CountrySelect(el | '#selector', options) for manual use.

Methods

CountrySelect.getInstance(el)Instance of an element (or null)
CountrySelect.init(root)Initialize .country-select inside root
cs.setValue(v, {silent})Select by value; sends events unless silent
cs.getValue()Current value
cs.getCountry(){code, name, localName, phone, value} or null
cs.open() · close() · toggle()Dropdown
cs.setCountries(list)New list: array, function, JSON, URL
cs.refresh()Re-read the value after input.value = …
cs.destroy()Remove the widget, restore the input
cs.readyPromise – resolved when the list is loaded

Events (on the input)

input.addEventListener('country-change', (e) => {
    e.detail.value;    // "GR"
    e.detail.country;  // {code, name, localName, phone, value}
});
