About CountrySelect Pro

CountrySelect Pro is a lightweight and dependency-free country picker built with vanilla JavaScript. It provides fast searching, phone prefix selection and Bootstrap-friendly UI while keeping the bundle extremely small.

  • 🚀 Zero dependencies
  • 🎨 Bootstrap 5 (and dark mode) or plain CSS with --cs-* variables
  • 📋 Built-in list or your own: array, JSON, URL, <select>
  • 🔍 Accent-insensitive search by name, ISO or phone code
  • 🌐 Country names in any language
  • ♿ Keyboard & screen reader accessible
  • 🔁 htmx ready
Basic Usage
<input class="country-select" name="country" value="GR">

<!-- or with JavaScript -->
<input id="country" name="country">
<script>
  new CountrySelect("#country", { defaultCountry: "GR", preferredCountries: ["GR", "CY"] });
</script>
